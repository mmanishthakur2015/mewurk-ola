# ⚡ Mewurk Website Clone - OLA Theme Applied

Aapka Mewurk website ka pura responsive frontend **OLA Theme** (Vibrant Electric Green `#00d26a` & Jet Black `#121418` with Sporty Lime `#d6df22`) ke saath alag folder **`C:\mewurk-ola`** me taiyaar hai!

---

## 📁 Folder Structure (C:\mewurk-ola)

```text
C:\mewurk-ola\
│
├── index.html          # Pura Mewurk Website (All 12+ sections, 9 modules, AI suite, footer)
├── README.md           # Yeh guide file
├── render.yaml         # Render configuration file (Name: mewurk-ola)
│
├── css\
│   ├── theme.css       # 🎨 THEME SETTINGS (Yahan se color theme change hoga)
│   └── style.css       # Layouts, components, responsive breakpoints, animations
│
└── js\
    └── main.js         # Interactive features, live theme switcher, mobile drawer, counter
```

---

## 🚀 Website Kaise Open Karein?

1. Apne computer me **File Explorer** kholein aur jayein:  
   👉 `C:\mewurk-ola`
2. **`index.html`** file par double-click karein.  
   Yeh aapke Google Chrome ya Microsoft Edge browser me open ho jayegi!
